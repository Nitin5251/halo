# DevShop

## Project Title
DevShop - Static E-Commerce Website

## Project Objective
The objective of this project is to build a simple static e-commerce website using HTML, CSS, and JavaScript while learning Git and GitHub version control workflows.

## Folder Structure
```
DevShop/
│── README.md
│── index.html
│── about.html
│── products.html
│── contact.html
│── login.html
│── css/
│   └── style.css
│── js/
│   └── script.js
```

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Git Workflow
- Initialize a Git repository.
- Create feature branches.
- Develop features independently.
- Commit changes with meaningful commit messages.
- Push branches to GitHub.
- Merge feature branches into the main branch using Pull Requests.
